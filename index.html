02
Backend / transactional correctness

ERP & CRM Operations Portal

A REST API for customers, inventory, and sales documents. Stock deductions, document creation, and ledger writes stay atomic, while query and index tuning reduce response latency.

TypeScriptNode.js / ExpressPostgreSQLDocker
Read the engineering notes
  • Correctness: SELECT FOR UPDATE locking, guarded updates, and a database CHECK constraint prevent negative inventory.
  • API design: More than 25 endpoints with four-role access control, JWT authentication, Zod validation, and structured error responses.
  • Performance: API latency reduced from 800 ms to 120 ms through query and index tuning; more than 10,000 requests per day and 50,000 core-table rows supported.
  • Quality: 85% Pytest coverage. Docker packaging and AWS deployment preparation using RDS, ECS, EC2, and CloudWatch.

03
Cloud / automated delivery

Autonomous Cloud Defense

An incident-response project connecting detection, diagnosis, remediation, and verification through eight LangGraph agents. A simulated attack loop exercises the workflow with a traceable audit history.

Python / FastAPIPostgreSQLGitHub ActionsAWS / Docker
Read the engineering notes
  • Workflow: Structured state and severity-based routing connect eight specialized agents. Gemini supports root-cause explanations and remediation planning.
  • Scale: More than 50,000 simulated events per day, over one million persisted rows, and more than 500 concurrent WebSocket connections.
  • Delivery: GitHub Actions CI/CD with 90% Pytest coverage, images in AWS ECR, and zero-downtime deployment on AWS EC2.
  • Client updates: Socket.IO streams incident and agent-state changes with sub-second latency.

These figures describe the project and its simulated workload, not live gaming-platform traffic.
